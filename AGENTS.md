# Правила проекта

- После каждого завершённого изменения: `npm run build` зелёный → `git add -A` → `git commit` → `git push` (всегда).
- Никогда не коммитить `.env.local` и секреты.
- Изменения схемы БД — только одним новым файлом миграции `supabase/migrations/00X_*.sql` поверх уже применённых (не редактировать 001–004 после первого применения).
- Интерфейс на русском.
- Полная инструкция по запуску: `INSTRUCTIONS.md`.
